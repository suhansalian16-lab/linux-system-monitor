# Linux System Monitor

A simple real-time system monitor built with Python and psutil.

## Features

- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- System uptime
- Network data sent and received
- Warnings for high CPU, RAM, and disk usage
- Real-time monitoring

## Technologies Used

- Python
- Linux
- psutil
- Git
- GitHub
